# Project conventions

## Language

The project owner explicitly requires this repository to remain in English. Use English for README files, documentation, code comments, identifiers, user-facing application text, issues, pull requests, and commit messages. Preserve this convention in future work unless the owner explicitly changes it. Private conversations and review materials outside the repository may use Chinese.

## Accuracy

Clearly distinguish proposed capabilities from implemented behavior. Do not claim experiments or tests have run without evidence. The repository starts in the planning stage.

## Attribution and secrets

Attribute reused open-source code and comply with its license. Never commit API keys, credentials, local secrets, or private collaboration correspondence.
